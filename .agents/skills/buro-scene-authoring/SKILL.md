# Из авторского текста в сцену

Возьми [карточку сцены](../../../docs/SCENE_TEMPLATE.md). Если задан только один разговор, подготовь этот разговор. Для заявки на целую серию используй также [шаблон серии](../../../docs/EPISODE_TEMPLATE.md).

1. Найди в исходнике цель игрока, участников и момент первого действия. Сохрани формулировки реплик, порядок событий и явно заданные исходы. Свою переходную реплику пометь «СВЯЗКА», предложенный вариант правила или числа пометь «Предложение». Эти пометки предназначены для автора.
2. Для каждого доступного выбора укажи, что видно игроку, при каком условии доступно действие, как реагирует собеседник и куда ведёт результат. Если ветки сходятся, назови общий следующий шаг и разницу, которая до него дошла (например, потраченное время).
3. Если есть улика, свяжи наблюдение с одним конкретным будущим решением. Отдельно запиши, можно ли принять решение без осмотра. Учти повторный клик или повторную попытку, если игрок может вернуться.
4. Пройди сцену по карточке глазами игрока. Проверь, что у него есть основание для осмысленного выбора, а итог каждой описанной ветки можно увидеть в игре. Если исходник обрывается, сохрани готовую часть и обозначь открытый вопрос рядом с недостающим переходом.

Для черновика достаточно результата в ответе, если автор не просил записать файл. Выбирай механику по действию автора. У «Бухгалтерии» четыре механики с отношением и дедлайном, у [«Дня контрольных»](../../../docs/EDUCATION.md) пять уроков с оценками и силами. При разборе сохраняй ресурсы и критерии именно выбранного сценария. [Данные «Бухгалтерии»](../../../scripts/rounds_data.gd) · [Данные школы](../../../scripts/school_data.gd)
